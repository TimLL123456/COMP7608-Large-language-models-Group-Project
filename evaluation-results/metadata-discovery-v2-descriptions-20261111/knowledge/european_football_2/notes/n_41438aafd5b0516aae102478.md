# Player table definition

Type: table
Table: Player
Scope: table_definition
Summary: Player profiles contain API identifiers, name, birthday, height and weight, and link to player IDs in match lineup slots.
Keywords: player, identity, birthday, name, height, weight, api id
Status: provisional
Sources: schema:Player DDL; values:Player COUNT(*), COUNT(height) observed; schema:Match references Player.player_api_id

## Business Summary
Stores player identity and profile fields, including API identifiers, name, birthday, height and weight.
## Business Use Cases
Join player profiles to dated Player_Attributes and Match records by player API ID; filter by player name or birthday.
## Data Granularity
One row per player profile; `id` is primary key and `player_api_id` and `player_fifa_api_id` are declared UNIQUE.
## Data Scope & Exclusions
11,060 rows observed; height populated for all. Dataset coverage, birthday completeness and measurement units are Unknown / Not verified.
