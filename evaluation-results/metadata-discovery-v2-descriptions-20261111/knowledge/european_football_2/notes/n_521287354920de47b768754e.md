# League table definition

Type: table
Table: League
Scope: table_definition
Summary: League lookup table associates a league identifier and name with a country identifier.
Keywords: league, country, competition, name
Status: provisional
Sources: schema:League (DDL columns, primary key, unique name, and country foreign key); description:League.csv:1-3

## Business Summary
Lookup table containing league id, country_id, and league name.
## Business Use Cases
Identifies a competition referenced by Match.league_id; league names can be used to select a competition.
## Data Granularity
One row per league entry; id is primary key and name is declared unique in the schema.
## Data Scope & Exclusions
Available leagues and coverage period are Unknown / Not verified. Country relationship is represented by country_id.
