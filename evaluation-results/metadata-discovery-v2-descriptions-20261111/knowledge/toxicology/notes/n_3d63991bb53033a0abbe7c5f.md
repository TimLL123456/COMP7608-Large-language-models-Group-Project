# atom.element

Keywords: atom, element, code, chemical element

## Business Meaning
Chemical element code assigned to an atom record.
## Business Usage
Classifies atoms by element; can report elements of atoms selected by connectivity criteria.
## Value Meaning
Nullable TEXT. Source description maps codes including cl (chlorine), c (carbon), h (hydrogen), o (oxygen), s (sulfur), n (nitrogen), p (phosphorus), na (sodium), br (bromine), f (fluorine), i (iodine), sn (tin), pb (lead), te (tellurium), and ca (calcium).
