## Business Summary
Stores atom identifiers, molecule associations, and element codes.
## Business Use Cases
Supports classifying atoms by element and grouping atom records by molecule_id.
## Data Granularity
One row per atom record. atom_id is a declared primary key; schema does not establish one record per molecule or stronger element completeness. Current observed rows have distinct atom_id values.
## Data Scope & Exclusions
molecule_id and element are nullable by schema. Source-described codes include c for carbon and cl for chlorine; other coverage is Unknown / Not verified.
