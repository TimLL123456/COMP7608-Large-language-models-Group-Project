# Molecule records

Type: table
Table: molecule
Scope: table_definition
Summary: Molecule records contain a declared primary-key ID and optional classification label, and relate to atom and bond records.
Keywords: molecule, molecule_id, label, atom, bond, primary key
Status: provisional
Sources: schema:molecule DDL: molecule_id TEXT NOT NULL PRIMARY KEY and nullable label; schema:atom.molecule_id and schema:bond.molecule_id foreign keys

## Business Summary
Stores molecule identifiers and an optional classification label.
## Business Use Cases
Supports grouping molecules by label and relating molecule_id to associated atom and bond records.
## Data Granularity
One row per molecule; molecule_id is TEXT NOT NULL and declared primary key.
