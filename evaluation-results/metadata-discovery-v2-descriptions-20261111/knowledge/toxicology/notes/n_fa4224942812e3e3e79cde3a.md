# connected.bond_id

Type: column
Table: connected
Scope: bond_id
Summary: Optional bond identifier for an atom pair; FK to bond.bond_id. Connectivity data can contain both endpoint orientations for a bond.
Keywords: connected, bond_id, bond, endpoint pair, foreign key
Status: provisional
Sources: schema:connected.bond_id TEXT DEFAULT NULL FOREIGN KEY references bond.bond_id; values:TR397 connectivity rows counted by atom endpoint and bond_id showed 178 rows, 89 distinct bond IDs and 0 null bond IDs

## Business Meaning
Optional identifier of the bond associated with an atom endpoint pair in a connectivity row.
## Business Usage
Join to bond.bond_id to retrieve bond attributes; connectivity rows may be used to identify atom neighbors through atom_id and atom_id2.
## Value Meaning
Text identifier, nullable by schema, with FK to bond.bond_id. Observed TR397 connectivity data has no NULL bond IDs and rows reflect reversed endpoint orientations for bonds; this pattern is not guaranteed by schema.

N/A; source/pass-through identifier.
