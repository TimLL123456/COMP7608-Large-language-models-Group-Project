# Atom connectivity records

Type: table
Table: connected
Scope: table_definition
Summary: Stores ordered atom endpoint pairs with optional bond IDs; endpoints link to atom records and bond IDs to bond records.
Keywords: connected, atom, endpoint, bond, connectivity
Status: provisional
Sources: schema:connected DDL composite primary key and foreign keys; values:SELECT COUNT(*), COUNT(DISTINCT bond_id), SUM(bond_id IS NULL) FROM connected; values:SELECT bond_id, atom_id, atom_id2 FROM connected ORDER BY bond_id, atom_id, atom_id2 LIMIT 10; values:SELECT bond_id, COUNT(*) FROM connected GROUP BY bond_id HAVING COUNT(*) <> 2

## Business Summary
Stores atom endpoint pairs and their associated bond identifiers.
## Business Use Cases
Join both endpoint IDs to atom records to classify endpoint elements; bond_id links to bond records.
## Data Granularity
One ordered (atom_id, atom_id2) pair per row; composite primary key. Current data has exactly two opposite orientations per non-null bond_id; the schema does not guarantee that pattern.
## Data Scope & Exclusions
Endpoint IDs reference atom.atom_id; bond_id optionally references bond.bond_id. Broader completeness and semantic constraints are Unknown / Not verified.
