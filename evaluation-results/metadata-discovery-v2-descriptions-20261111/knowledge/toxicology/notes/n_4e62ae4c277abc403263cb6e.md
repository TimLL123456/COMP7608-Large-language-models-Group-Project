# connected.atom_id

Type: column
Table: connected
Scope: atom_id
Summary: First atom endpoint identifier in a connectivity pair; required text FK to atom.atom_id.
Keywords: connected, atom_id, endpoint, foreign key, atom
Status: provisional
Sources: schema:connected.atom_id TEXT NOT NULL foreign key references atom.atom_id; values:SELECT c.atom_id, c.atom_id2, c.bond_id FROM connected c JOIN atom a1 ON a1.atom_id=c.atom_id JOIN atom a2 ON a2.atom_id=c.atom_id2 WHERE a1.molecule_id='TR397' LIMIT 12

## Business Meaning
Identifier of the first atom endpoint in a connectivity row.
## Business Usage
Join to atom.atom_id to access the endpoint's molecule and element attributes; paired with atom_id2 it identifies both endpoints.
## Value Meaning
Text identifier; schema declares NOT NULL and a foreign key to atom.atom_id. Sampled TR397 connectivity rows show that the referenced endpoint atoms can be associated to TR397. No additional code interpretation verified.
