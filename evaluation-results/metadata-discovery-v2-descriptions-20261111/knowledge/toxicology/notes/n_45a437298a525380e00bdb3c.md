# molecule.label

Type: column
Table: molecule
Scope: label
Summary: Optional molecule label; observed '+' denotes carcinogenic per supplied evidence, and '-' is identified as non-carcinogenic.
Keywords: molecule, label, carcinogenicity, classification
Status: provisional
Sources: schema:molecule.label TEXT DEFAULT NULL; values:SELECT label, COUNT(*) AS n FROM molecule GROUP BY label; description:question evidence specifies '+' as carcinogenic; description:existing note evidence identifies '-' as non-carcinogenic

## Business Meaning
Optional label attached to a molecule; used as a molecule classification code.
## Business Usage
Can filter/group molecule records by classification and associate them with atom data using molecule_id.
## Value Meaning
Observed codes are '+' and '-'. Supplied evidence identifies '+' as carcinogenic and existing verified note evidence identifies '-' as non-carcinogenic.

N/A; source/pass-through field.
