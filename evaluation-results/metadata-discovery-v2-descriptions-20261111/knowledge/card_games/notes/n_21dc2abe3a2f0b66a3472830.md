## Business Summary
Stores foreign-language card data including language, localized name, type, text, and flavor text fields.
## Business Use Cases
Can connect language-specific card data to a cards record through uuid = cards.uuid; supports identifying language records associated with a card record.
## Data Granularity
One row per stored language-specific card-data record; id is an integer primary key and uuid references cards.uuid. Uniqueness of card-language rows and set/card-number granularity are Unknown / Not verified.
## Data Scope & Exclusions
Schema establishes foreign-language card fields and the UUID relation but not completeness or whether a record documents an actual release of a printing in that language. Dataset coverage is Unknown / Not verified.
