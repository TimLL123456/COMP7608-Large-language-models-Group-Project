# Card layout

Type: column
Table: cards
Scope: layout
Summary: TEXT layout category; all observed adventure, aftermath, flip, meld, modal_dfc, split, and transform records have both faceName and otherFaceIds populated.
Keywords: layout, card face, split, transform, adventure, modal_dfc
Status: provisional
Sources: schema:cards.layout TEXT; schema:cards.faceName TEXT and otherFaceIds TEXT; values:cards GROUP BY layout with counts of nonempty faceName and otherFaceIds

## Business Meaning
Indicates the layout category associated with a card record; source documentation calls it the type of card layout.
## Business Usage
Can classify records by layout. Every observed adventure, aftermath, flip, meld, modal_dfc, split, and transform record has nonempty faceName and otherFaceIds, indicating associated face details. This does not establish exact face count or an exhaustive physical-card taxonomy.
## Value Meaning
TEXT. Observed layout categories with both faceName and otherFaceIds populated: adventure, aftermath, flip, meld, modal_dfc, split, transform. Other observed categories lacked both fields. These are dataset observations, not a universal taxonomy.
## Calculation Meaning
N/A; source/pass-through field.
