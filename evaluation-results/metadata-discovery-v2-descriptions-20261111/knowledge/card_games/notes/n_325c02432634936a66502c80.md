# Card record UUID

Type: column
Table: cards
Scope: uuid
Summary: Unique, non-NULL text UUID identifies a stored card row and is referenced by ruling rows; identity across printings is not established.
Keywords: uuid card identifier rulings printing
Status: provisional
Sources: schema:cards DDL uuid TEXT NOT NULL UNIQUE; schema:legalities DDL uuid references cards(uuid); schema:foreign_data DDL uuid references cards.uuid; schema:rulings DDL uuid references cards(uuid)

## Business Meaning
Text identifier assigned to a stored card record.
## Business Usage
rulings.uuid references cards.uuid, permitting ruling-row linkage to a card record. This does not establish that UUID represents one conceptual card across all printings.
## Value Meaning
TEXT; cards.uuid is declared UNIQUE and NOT NULL.
## Calculation Meaning
N/A; source/pass-through field.
