# Card type categories

Type: column
Table: cards
Scope: types
Summary: TEXT field for card type categories; observed values include Artifact and Artifact,Creature, allowing combined-type classification.
Keywords: types, artifact, creature, card category
Status: provisional

## Business Meaning
Text field holding one or more card type categories, distinct from visible type line field `type`.
## Business Usage
Can filter/classify records by type category; observed Artifact and comma-separated category combinations support identifying artifact cards including artifact creatures.
## Value Meaning
Observed values include Artifact and Artifact,Creature. Full domain and edge-case formatting are Unknown / Not verified.
