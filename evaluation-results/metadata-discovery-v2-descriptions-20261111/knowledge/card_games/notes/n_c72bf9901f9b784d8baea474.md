# Card set code

Type: column
Table: cards
Scope: setCode
Summary: Text set identifier on a cards row; unique UUID supports record counts, but official language-specific printing coverage is not represented here.
Keywords: set code, card, set, printing record, identifier
Status: provisional
Sources: schema:cards.setCode TEXT; schema:cards.uuid UNIQUE NOT NULL; schema:sets.code TEXT NOT NULL UNIQUE; values:cards aggregate found no null or unmatched setCode values

## Business Meaning
Set code associated with a card record, corresponding to the catalog identifier in sets.code in observed data.
## Business Usage
Can link card records to set catalog attributes. `cards.uuid` is declared unique per row, but data does not map each record to an officially issued printing language.
## Value Meaning
TEXT; observed card setCode values were non-null and matched corresponding sets.code values. Code interpretation and official language coverage are Unknown / Not verified.
