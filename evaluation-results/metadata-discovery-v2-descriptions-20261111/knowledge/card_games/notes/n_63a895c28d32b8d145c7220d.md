# Set catalog row ID

Type: column
Table: sets
Scope: id
Summary: Integer primary key identifying a set catalog row; not interchangeable with its unique set code.
Keywords: sets, row id, primary key, identifier
Status: provisional
Sources: schema:sets DDL id INTEGER primary key autoincrement

## Business Meaning
Integer identifier of a set catalog row.
## Business Usage
Can identify a set listing row; set codes are a separate identifier and translation relation uses sets.code.
## Value Meaning
INTEGER primary key, autoincrement. Uniqueness follows primary-key constraint.
