## Business Meaning
Date identified as the release date for a set in the source catalog.
## Business Usage
Supports selecting set records by release-day intervals; an inclusive year can be expressed as >= Jan 1 and < Jan 1 of the next year.
## Value Meaning
Declared DATE; source documents ISO 8601 format. Observed dates use YYYY-MM-DD.
