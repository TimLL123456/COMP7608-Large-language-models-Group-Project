# Legality record ID

Type: column
Table: legalities
Scope: id
Summary: Integer primary key identifying an individual stored legality row; generated by autoincrement.
Keywords: legalities, record id, primary key
Status: provisional
Sources: schema:legalities DDL id INTEGER NOT NULL PRIMARY KEY AUTOINCREMENT; schema:legalities DDL uuid references cards(uuid)

## Business Meaning
Identifier for an individual card-format legality record.
## Business Usage
Distinguishes stored legality rows; not a card identifier (uuid links to cards).
## Value Meaning
Integer primary key with autoincrement declared in schema.
## Calculation Meaning
Generated by SQLite autoincrement for inserted rows; existing ID assignments are not independently verified.
