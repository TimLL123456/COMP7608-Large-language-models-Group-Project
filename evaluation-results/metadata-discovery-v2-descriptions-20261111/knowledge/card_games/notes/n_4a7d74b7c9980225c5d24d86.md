## Business Summary
Catalog records identify sets and carry labels, release dates, and size attributes.
## Business Use Cases
Can select sets by release date with code as a tie-breaker and associate cards through cards.setCode = sets.code; comparison of documented sizes may be relevant to set analysis.
## Data Granularity
One row per catalog set; code is declared unique and id primary key in schema.
## Data Scope & Exclusions
Includes varied catalog types (observed commander, expansion, promo, core); broader coverage and official release-language information are Unknown / Not verified. Catalog's definition of a set and completeness are Unknown / Not verified.
