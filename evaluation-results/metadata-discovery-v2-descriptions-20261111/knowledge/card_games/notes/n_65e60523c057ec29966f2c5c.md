## Business Meaning
Label associated with the frame style on a card record; source description calls it the version of the card frame style.
## Business Usage
Group records by frame-style label. Numeric year-like labels can be compared by year; the special value 'future' cannot be assigned a verified year based on available evidence.
## Value Meaning
TEXT; observed values are 1993, 1997, 2003, 2015, and 'future'. Schema documentation says timeshifted cards can have a different frameVersion. All observed numeric labels are listed above; 'future' occurs as a separate label. Its numeric frame-introduction year is Unknown / Not verified. Set release dates do not verify that year.
