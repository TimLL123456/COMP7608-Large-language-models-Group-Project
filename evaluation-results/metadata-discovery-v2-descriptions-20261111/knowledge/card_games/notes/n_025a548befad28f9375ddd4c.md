# Set name

Type: column
Table: sets
Scope: name
Summary: Text name on a sets catalog record; localization is represented separately in set_translations, and name language is not determined by its text.
Keywords: set name, catalog, localization, translation
Status: provisional
Sources: schema:sets DDL name TEXT; schema:set_translations DDL translation TEXT and setCode references sets.code

## Business Meaning
Name label associated with a set catalog record; it is not verified to be an English-language-only field.
## Business Usage
Identifies/displays a set; stored translations are represented separately in set_translations by setCode.
## Value Meaning
TEXT string; language cannot reliably be inferred from this field alone.
## Calculation Meaning
N/A; source/pass-through field.
