# Budget table definition

Type: table
Table: budget
Scope: table_definition
Summary: Budget rows are category-level entries linked to events; expenses reference entries, and amount is per entry, not verified as event total.
Keywords: budget, event, category, amount, spent, expense, entry
Status: provisional
Sources: schema:budget DDL; schema:budget.link_to_event REFERENCES event(event_id); schema:expense.link_to_budget REFERENCES budget(budget_id); description:Budget.csv:3; values:budget 52 rows, 23 event IDs; values:expense descriptions containing chips linked to Food budget entries

## Business Summary
Stores budget entry IDs, category, planned amount, spent and remaining values, status, and event reference.
## Business Use Cases
Supports category allocations and event spending. Expenses reference budget entries; observed expense descriptions containing chips link to Food entries, a practical observed identification method, not a formal taxonomy.
## Data Granularity
One row per budget entry by declared primary key budget_id; no one-row-per-event rule is verified.
## Data Scope & Exclusions
budget.link_to_event references event.event_id; expense.link_to_budget references budget.budget_id. Observed 52 budget rows cover 23 events. Completeness and treatment of events without budget rows are Unknown / Not verified.
