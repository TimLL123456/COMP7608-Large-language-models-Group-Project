# Expense budget reference

Type: column
Table: expense
Scope: link_to_budget
Summary: Expense field references budget.budget_id, allowing expenses to associate with budget entries and their events.
Keywords: expense, budget, reference, event, identifier
Status: provisional
Sources: schema:expense.link_to_budget REFERENCES budget(budget_id); schema:budget.link_to_event REFERENCES event(event_id)

## Business Meaning
Reference from an expense record to a budget entry.
## Business Usage
Join expense.link_to_budget to budget.budget_id; the budget entry can then be associated with an event through budget.link_to_event.
## Value Meaning
TEXT identifier referencing budget.budget_id via declared foreign key.
## Calculation Meaning
N/A; source/pass-through reference field.
