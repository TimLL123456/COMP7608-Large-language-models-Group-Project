# Event status

Type: column
Table: event
Scope: status
Summary: Text status recorded for an event; observed values include Closed, Open, and Planning.
Keywords: event, status, closed, open, planning
Status: provisional
Sources: schema:event.status TEXT; values:event DISTINCT status observed Closed, Open, Planning

## Business Meaning
Status label recorded on an event.
## Business Usage
Can be used to filter event records by recorded status; for example, Closed identifies events with that status value.
## Value Meaning
TEXT; observed values include Closed, Open, and Planning. Other possible values are Unknown / Not verified.
