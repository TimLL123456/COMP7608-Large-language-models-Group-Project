# Expense identifier

Type: column
Table: expense
Scope: expense_id
Summary: Declared TEXT primary key for an expense record; identifies records, not a verified count of items purchased.
Keywords: expense, identifier, primary key, record, occurrence
Status: provisional
Sources: schema:expense DDL and columns; schema:expense.expense_id TEXT primary key

## Business Meaning
Identifier for an expense record.
## Business Usage
Supports referencing individual expense records. Expense rows can be counted as expense-record occurrences; the schema does not verify that one record equals one item purchased or that a description lists individual purchases.
## Value Meaning
TEXT identifier; special code interpretation is Unknown / Not verified.
## Calculation Meaning
N/A; source/pass-through field.
