# Attendance table definition

Type: table
Table: attendance
Scope: table_definition
Summary: Associates member IDs with event IDs; composite primary key models one recorded row per member-event pair.
Keywords: attendance, member, event, association, composite key
Status: provisional
Sources: schema:attendance DDL and foreign keys; description:Attendance.csv:1; description:Attendance.csv:2

## Business Summary
Associates member references with event references to record attendance.
## Business Use Cases
Supports identifying which members are recorded as attending each event; foreign keys reference member.member_id and event.event_id.
## Data Granularity
One row per member-event pair, with composite primary key (link_to_event, link_to_member).
## Data Scope & Exclusions
Schema models only member-event associations. Other attendance details and completeness of records are Unknown / Not verified.
