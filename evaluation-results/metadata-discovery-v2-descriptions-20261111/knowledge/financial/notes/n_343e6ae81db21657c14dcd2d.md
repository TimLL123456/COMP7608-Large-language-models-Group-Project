# Loan status

Type: column
Table: loan
Scope: status
Summary: Non-null TEXT code on loan; supplied task evidence identifies C and D as active and A and B as finished.
Keywords: loan, status, repayment, active, finished, code

## Business Meaning
A repayment-status code recorded for a loan.
## Business Usage
Can classify loans by repayment status; supplied task evidence identifies statuses C and D as active, excluding finished A and B.
## Value Meaning
TEXT NOT NULL. According to supplied task evidence: A and B are finished contracts; C is active in good standing; D is active with the client in debt. Meanings beyond these task-provided definitions are Unknown / Not verified.

N/A; source/pass-through status code.
