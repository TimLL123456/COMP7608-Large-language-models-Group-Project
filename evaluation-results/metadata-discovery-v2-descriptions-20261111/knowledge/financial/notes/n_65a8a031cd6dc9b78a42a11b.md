# Account records

Type: table

Scope: table_definition
Summary: Account rows identify accounts and the district serving as branch location; disposition links clients to accounts.
Keywords: account, branch, district, disposition, frequency

## Business Summary
Stores account identifiers, district/branch location, statement frequency, and account creation date.
## Business Use Cases
Supports analyses by branch location; clients are associated to accounts through disposition records.
## Data Granularity
One row per account_id, declared primary key.
## Data Scope & Exclusions
account.district_id references district.district_id; dataset description calls it location of branch. Account has no client_id, and branch naming or historical location behavior is Unknown / Not verified.
