# Payment order purpose code

Type: column
Table: order
Scope: k_symbol
Summary: Recorded classification code describing the purpose of a payment order.
Keywords: order, payment purpose, code, k_symbol
Status: provisional
Sources: schema:order.k_symbol (TEXT, NOT NULL); description:order.csv:6 (documented code meanings)

## Business Meaning
Characterization/classification of the payment purpose for a payment order.
## Business Usage
Can classify or group payment orders by recorded purpose code.
## Value Meaning
TEXT NOT NULL. Description documents POJISTNE as insurance payment, SIPO as household payment, LEASING as leasing, and UVER as loan payment. Other values are Unknown / Not verified.
## Calculation Meaning
N/A; source/pass-through field.
