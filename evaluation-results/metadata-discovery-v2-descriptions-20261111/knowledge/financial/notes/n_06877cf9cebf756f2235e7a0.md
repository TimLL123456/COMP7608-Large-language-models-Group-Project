# Transaction owner account ID

Type: column
Table: trans
Scope: account_id
Summary: Required account link identifying the account whose transaction is recorded.
Keywords: transaction, account, foreign key
Status: provisional
Sources: schema:trans.account_id INTEGER NOT NULL FK account.account_id

## Business Meaning
Account identifier for the account whose transaction row is recorded.
## Business Usage
Links each transaction to account.account_id for account activity analysis and branch-district filtering through account.district_id.
## Value Meaning
INTEGER NOT NULL, foreign key to account.account_id.
## Calculation Meaning
N/A; source/pass-through identifier.
