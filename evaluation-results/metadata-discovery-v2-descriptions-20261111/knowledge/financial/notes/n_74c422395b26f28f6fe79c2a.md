# Transaction direction/category code

Type: column
Table: trans
Scope: type
Summary: Required TEXT transaction category; PRIJEM denotes credit/received and VYDAJ debit/withdrawn per task evidence; VYDAJ includes transfers and withdrawals.
Keywords: transaction, type, prijem, vydaj, credit, debit
Status: provisional
Sources: schema:trans.type TEXT NOT NULL; description: supplied task evidence defines PRIJEM as credit and VYDAJ as debit; values:trans type/operation groups show VYDAJ includes PREVOD NA UCET, VYBER, and VYBER KARTOU

## Business Meaning
Required transaction direction/category code for a recorded account transaction.
## Business Usage
Use PRIJEM to identify credit transactions described as received and VYDAJ for debit transactions described as withdrawn in supplied task evidence. VYDAJ includes transfer and withdrawal operations in observed rows; operation differentiates these activity kinds.

TEXT NOT NULL. Observed codes include PRIJEM, VYDAJ, and VYBER; complete code dictionary Unknown / Not verified.
