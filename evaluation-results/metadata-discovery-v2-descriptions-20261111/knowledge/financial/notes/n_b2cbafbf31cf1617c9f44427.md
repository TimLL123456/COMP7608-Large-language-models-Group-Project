# Transaction purpose characterization

Type: column

Summary: Nullable TEXT transaction characterization; documented SIPO means household payment; NULL means no recorded tag; blank-space value meaning unresolved.

## Business Meaning
Transaction characterization or purpose tag associated with a transaction.
## Business Usage
Can classify transaction rows by their recorded purpose; distinguishes SIPO household payment from missing tags and other recorded values.
## Value Meaning
Nullable TEXT. Supplied task evidence maps SIPO to household payment and NULL to no purpose recorded. Observed non-null codes include SIPO, UROK, SLUZBY, DUCHOD, POJISTNE, UVER, SANKC. UROK, plus a single-space string whose meaning is Unknown / Not verified. Meanings of other codes are not fully verified.
