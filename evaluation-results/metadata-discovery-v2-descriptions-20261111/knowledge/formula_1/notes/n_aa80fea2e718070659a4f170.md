# Race starting grid position

Type: column
Table: results
Scope: grid
Summary: INTEGER grid field on a race result; provides the recorded starting-grid position, distinct from qualifying position.
Keywords: results, grid, starting position, race
Status: provisional
Sources: schema:results DDL (grid INTEGER default 0 not null); schema:results foreign keys

## Business Meaning
Starting-grid position associated with a driver's race result.
## Business Usage
Can be used to establish which driver started higher on the grid, including resolving tied qualifying times when linked by race and driver.

INTEGER, NOT NULL with schema default 0. Specific meanings for exceptional values such as zero are Unknown / Not verified.
