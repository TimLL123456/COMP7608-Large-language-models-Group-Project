# Q3 qualifying time

Type: column
Table: qualifying
Scope: q3
Summary: Nullable TEXT timing field for a qualifying record's Q3 segment; observed timing strings, NULLs, and empty strings.
Keywords: qualifying, q3, timing, session, mm:ss.mmm
Status: provisional
Sources: schema:qualifying DDL q3 TEXT nullable and driverId foreign key to drivers.driverId; values:qualifying.q3 observed NULL, empty strings, and m:ss.mmm timing strings

## Business Meaning
Text field for a qualifying record's time in the Q3 segment.
## Business Usage
Used to identify a recorded Q3 time for a qualifying record; qualifying.driverId references drivers.driverId.
## Value Meaning
Nullable TEXT; observed values include NULL, empty strings, and m:ss.mmm timing strings. Nonempty values represent recorded Q3 times.
## Calculation Meaning
Source/pass-through field. To identify fastest time, compare parsed durations numerically; raw lexical ordering is not generally guaranteed to represent time order.
