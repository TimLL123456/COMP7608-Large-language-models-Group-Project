# Fastest lap speed

Type: column
Table: results
Scope: fastestLapSpeed
Summary: TEXT average-speed value attached to a race result; valid nonblank observed values use numeric formatting, with many records blank.
Keywords: fastest lap, speed, result, km/h
Status: provisional
Sources: schema:results DDL fastestLapSpeed TEXT; schema:results foreign key driverId references drivers.driverId; values:results fastestLapSpeed blank count and nonblank character-format checks; description: question evidence describes speed in km/h (not independently verified)

## Business Meaning
Average speed associated with the fastest lap recorded for a race result; dataset context identifies the measure as km/h, though the schema specifies only TEXT.
## Business Usage
May compare a driver's recorded fastest-lap speeds across race results; career-high is derived by taking the maximum valid numeric speed per driver. Blank or NULL values are missing and should be excluded from numeric comparisons.
## Value Meaning
TEXT field. Observed nonblank values had no characters outside digits and decimal points; 18,185 of 23,179 rows were NULL or blank. No nonnumeric nonblank examples were observed. No special code/value interpretation verified.
## Calculation Meaning
Source/pass-through field. A career-high speed is a query-derived maximum after numeric conversion, not stored as such.
