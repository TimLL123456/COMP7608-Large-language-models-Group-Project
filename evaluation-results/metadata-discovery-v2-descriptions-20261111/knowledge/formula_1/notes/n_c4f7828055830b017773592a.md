# Race result status identifier

Type: column
Table: results
Scope: statusId
Summary: Non-null integer status code on a result row, linked to the status lookup table.
Keywords: results, statusid, status, result outcome
Status: provisional
Sources: schema:results DDL and foreign key statusId->status.statusId; schema:status DDL and status column

## Business Meaning
Identifier of the status associated with a race-result entry; references status.statusId.
## Business Usage
Join results.statusId to status.statusId to retrieve the stored status text.
## Value Meaning
Numeric identifiers correspond to labels in status.status; specific identifiers and label meanings require the lookup and should not be presumed.
## Calculation Meaning
N/A; source/pass-through field.
