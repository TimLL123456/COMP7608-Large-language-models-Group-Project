# Status lookup identifier

Type: column
Table: status
Scope: statusId
Summary: Integer primary-key identifier for a result status label; results.statusId references it.
Keywords: status, statusid, results, lookup, identifier
Status: provisional
Sources: schema:status DDL; schema:results foreign key statusId->status.statusId; values:status statusId 54 maps to Withdrew

## Business Meaning
Identifier for a recorded race-result status in the status lookup.
## Business Usage
Join status.statusId to results.statusId to interpret a result row's stored status label.
## Value Meaning
Integer primary key; the observed label “Withdrew” is associated with statusId 54. Other code meanings should be read from status.status; do not infer an ordering.
