## Business Summary
Stores patient-linked dated laboratory records with multiple chemistry, blood-count, coagulation, and antibody-related result fields.
## Business Use Cases
Supports analysis of laboratory records over time; ID links records to Patient.ID. Record existence means a dated Laboratory row; analyses requiring a measurement should test result fields for non-NULL values.
## Data Granularity
One row per (ID, Date), according to declared composite primary key. Each row has multiple nullable results; it is a dated record, not verified as one individual assay.
## Data Scope & Exclusions
ID and Date are non-null; listed result columns are nullable. In inspected data 26/13,908 rows had all listed result fields NULL, confirming row existence need not imply an observed result. Dataset coverage is Unknown / Not verified.
