## Business Summary
FRPM records contain school descriptors, grade span, K-12 and ages 5-17 enrollment, and meal eligibility counts/rates. Schema declares CDSCode primary key and foreign key to schools.CDSCode.
## Business Use Cases
Supports school-linked enrollment and meal eligibility analysis. Source description labels FRPM Count as Free or Reduced Price Meal Count and defines eligible FRPM rate as FRPM divided by Enrollment.
## Data Granularity
One row per CDSCode by declared primary key. Loaded extract has 9,986 records, all labeled Academic Year 2014-2015; no repeated CDSCode observed.
## Data Scope & Exclusions
Loaded extract provides one 2014-2015 record per included CDSCode; duplicate-year selection is not needed in this extract. Coverage rules, enrollment counting details, null handling, and completeness relative to all directory schools are Unknown / Not verified.
