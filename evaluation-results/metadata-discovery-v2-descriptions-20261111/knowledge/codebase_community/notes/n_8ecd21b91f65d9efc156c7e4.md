## Business Summary
Stores records connecting post identifiers through PostId and RelatedPostId, with CreationDate and LinkTypeId fields.

## Business Use Cases
Join either endpoint to posts.Id to examine link records attached to a post. Sampled links touching title-matching posts occur at either endpoint, so endpoint choice matters. LinkTypeId values 1 and 3 were observed, but their meanings and any intended inclusion rules are Unknown / Not verified.

## Data Granularity
One row per post-link record; Id is the primary key. Whether duplicate records can represent the same pair is Unknown / Not verified.

## Data Scope & Exclusions
Schema has nullable endpoint and type fields with foreign keys from both endpoints to posts.Id. Observed LinkTypeId values are 1 and 3; broader coverage, exclusions, and code meanings are Unknown / Not verified.
