# Comments table definition

Type: table
Table: comments
Scope: table_definition
Summary: Stores comment records linked to posts and optionally users, with text, score and creation date fields.
Keywords: comments, posts, text, author, creation date
Status: provisional
Sources: schema:comments DDL and foreign keys

## Business Summary
Stores comment records and their associated post, optional user, text, score, and creation timestamp.
## Business Use Cases
Retrieve comment text and timing for a post; associate a comment with its post and available user identity fields.
## Data Granularity
One row per comment Id; Id is a non-null primary key in the schema.
## Data Scope & Exclusions
PostId and UserId are nullable foreign keys to posts.Id and users.Id respectively. Other coverage and exclusions: Unknown / Not verified.
