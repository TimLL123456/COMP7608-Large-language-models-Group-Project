# Tags table definition

Type: table
Table: tags
Scope: table_definition
Summary: Catalog of tag names with associated counts and optional excerpt/wiki post references.
Keywords: tags, tag catalog, count, excerpt, wiki

## Business Summary
Catalogs tag records with a tag name, count, and optional references to excerpt and wiki posts.
## Business Use Cases
Look up a canonical tag name and inspect its recorded count or associated post references.
## Data Granularity
One row per tag Id; Id is NOT NULL PRIMARY KEY. Uniqueness of TagName is Unknown / Not verified.
## Data Scope & Exclusions
DDL provides nullable TagName, Count, ExcerptPostId, and WikiPostId; ExcerptPostId references posts.Id. Dataset coverage and meaning of count are Unknown / Not verified.
