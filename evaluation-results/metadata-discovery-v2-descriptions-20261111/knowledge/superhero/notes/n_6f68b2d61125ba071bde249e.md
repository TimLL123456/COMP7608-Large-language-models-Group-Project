# Superpower name

Type: column
Table: superpower
Scope: power_name
Summary: Nullable text label for a power record joined to heroes via hero_power; exact observed label includes Flight.
Keywords: power name, superpower, hero power, flight, label
Status: provisional
Sources: schema:superpower.power_name TEXT; schema:hero_power.power_id foreign key to superpower.id; values:superpower.power_name exact observed label Flight

## Business Meaning
Text label naming a superpower record.
## Business Usage
Join superpower.id through hero_power.power_id to associate a named power with superheroes; superhero.id connects via hero_power.hero_id.
## Value Meaning
Observed exact labels include Death Touch, Super Speed, and Flight; capitalization is as stored. The database does not verify that identical labels represent semantically equivalent abilities or that differently named labels differ in meaning.

N/A; source/pass-through field.
