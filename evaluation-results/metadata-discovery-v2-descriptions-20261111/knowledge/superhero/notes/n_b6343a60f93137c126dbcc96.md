# Superhero eye colour reference

Type: column
Table: superhero
Scope: eye_colour_id
Summary: Nullable foreign-key ID assigning a superhero record to a colour lookup record for eye colour.
Keywords: superhero, eye colour, colour id, foreign key
Status: provisional
Sources: schema:superhero.eye_colour_id nullable INTEGER foreign key to colour.id; description:superhero.csv:5

## Business Meaning
Identifies the referenced colour lookup record used for a superhero's eye colour.
## Business Usage
Join superhero.eye_colour_id to colour.id to obtain the label; null values mean no referenced eye-colour record. Description identifies this as the superhero's eye color ID.
## Value Meaning
Values reference colour.id; the label is stored in colour.colour. Special codes beyond this relationship are not verified.
