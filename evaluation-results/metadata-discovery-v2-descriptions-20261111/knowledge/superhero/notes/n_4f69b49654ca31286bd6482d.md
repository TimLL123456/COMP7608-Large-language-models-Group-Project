# Colour table definition

Type: table
Table: colour
Scope: table_definition
Summary: Lookup table containing colour identifiers and text labels used for superhero colour references.
Keywords: colour, lookup, eye, hair, skin
Status: provisional
Sources: schema:colour DDL; schema:superhero foreign keys; description:colour.csv:2

## Business Summary
Provides colour IDs and nullable text colour labels, referenced by superhero colour fields.
## Business Use Cases
Resolve a superhero's eye, hair, or skin colour ID to a display label.
## Data Granularity
One row per colour record; id is the primary key. Uniqueness of colour labels is not verified.
## Data Scope & Exclusions
Colour labels may cover skin, eye, hair, or other superhero-related colours; individual use is determined by the referencing superhero column.
