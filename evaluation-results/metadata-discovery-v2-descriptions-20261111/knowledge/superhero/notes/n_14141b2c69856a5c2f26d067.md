# Superhero alignment reference

Type: column
Table: superhero
Scope: alignment_id
Summary: Nullable foreign-key ID linking superhero records to alignment.id; join to alignment.alignment for the moral-alignment label.
Keywords: superhero, alignment, foreign key, alignment id, lookup
Status: provisional
Sources: schema:superhero.alignment_id INTEGER nullable foreign key to alignment.id; schema:alignment.alignment TEXT nullable

## Business Meaning
Nullable integer reference to the superhero record's alignment lookup entry.
## Business Usage
Join superhero.alignment_id to alignment.id to retrieve alignment.alignment labels.
## Value Meaning
Foreign-key references alignment lookup records; labels and meanings are defined by alignment.alignment. Specific IDs are not independently meaningful; null interpretation is Unknown / Not verified.
